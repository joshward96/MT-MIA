# Finding Connections: Membership Inference Attacks for the Multi-Table Synthetic Data Setting

This repository contains the official implementation of the paper **"Finding Connections: Membership Inference Attacks for the Multi-Table Synthetic Data Setting."** Our work explores how relational links between tables in synthetic datasets can be exploited to leak information about the membership of specific individuals in the private source data.

## Getting Started

### Prerequisites

* Anaconda or Miniconda
* Python 3.9+

### Installation

1. **Clone the repository:**

2. **Create and activate the environment:**
```bash
cd MT-MIA
conda env create -f environment.yml

```

## Reproducing Paper Experiments

To replicate the results presented in the paper, we provide a suite of automation scripts.

> **Note:** Generating multi-table synthetic data is computationally intensive. We have included pre-processed real data with fidelity metrics in `data/` and the pre-generated synthetic data used in our experimentation in `synth_data/` for ClavaDDPM, RealTabFormer, and RelDiff respectively. We also include the results of all MT-MIA and single-table attack runs generated by `./scripts/run_all_mtmia.sh` and `./scripts/run_all_single_table.sh` in the `results/` directory. To skip synthetic data generation, start from the third script below.

> **RelDiff note:** Generating RelDiff synthetic data is GPU-compute intensive — our runs required approximately 450 GPU-hours on H200s. That said, RelDiff itself has low VRAM requirements and can be run on consumer-grade GPUs given sufficient time. Pre-generated RelDiff data is included in `synth_data/reldiff_synth/`.

To run the entire pipeline, download the original raw data for each dataset from the anonymous link https://figshare.com/s/7aa6f39fbab903ef7699 and place each `data/DATASET_NAME/original/` into their respective directories under `data/DATASET_NAME/`.

This Run the following scripts in order to replicate the paper:

```bash
# 1. Prepare the datasets
./scripts/process_data.sh

# 2. Generate synthetic data (ClavaDDPM + RealTabFormer)
./scripts/generate_data.sh

# 2b. Generate RelDiff synthetic data (GPU-intensive; ~450 GPU-hours on H200s)
./scripts/generate_reldiff_airbnb.sh
./scripts/generate_reldiff_airlines.sh
./scripts/generate_reldiff_california.sh

# 3. Execute Membership Inference Attacks
./scripts/run_all_mtmia.sh          
./scripts/run_all_single_table.sh    

# 4. Evaluate synthetic data quality
./scripts/run_fidelity_eval.sh

```

The final tables and plots found in the paper can be generated using the Jupyter Notebooks located in the `notebooks/` directory.

## Using MT-MIA on New Datasets

To apply MT-MIA to your own synthetic relational data:

1. **Format your data:** Follow the directory structure and schema format shown in `data/toy/`. For best results, ensure there are no missing data and categorical variables are ordinally encoded.
2. **Configure your run:** Create a `.yaml` configuration file (refer to `configs/toy.yaml`).
3. **Run the attack:**

```bash
python run_MTMIA.py --config configs/toy.yaml
```
